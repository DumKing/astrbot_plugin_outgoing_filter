# 出站文本过滤

适用于 AstrBot 4.29.4，无需额外 Python 依赖。在插件卡片的齿轮中打开「规则列表」，选类型添加规则并保存。如果当前实例保存后没有应用，重载该插件。

- 文本规则按词条字面匹配，词条越长优先级越高（同一起点）。第一版用预编译正则匹配小词库。
- 链接规则支持 HTTP(S)、常见裸域名和 Markdown 链接。可以替换名单内或名单外的域名，并选择是否保留 Markdown 标题。
- 正则规则使用 Python 正则语法。替换内容按字面插入。复杂正则可能拖慢发送，建议使用简单的匹配表达式。
- 规则按保存的列表顺序执行。每条规则单独配置 UMO 黑白名单，白名单放行并优先于黑名单，只有命中黑名单才处理。黑名单留空时本规则不处理任何会话。例如 `napcat:GroupMessage:*`。
- 只处理 AstrBot 发送前装饰钩子收到的最外层文本段。合并转发节点不会展开。规则仅在各文本段内匹配。插件直接走平台接口发送、流式发送等路径的覆盖取决于 AstrBot 是否调用此钩子。

安装后规则列表为空。添加规则后，可先用单个测试会话的 UMO 黑名单验证。

## 调试规则

将 AstrBot 全局日志级别设为 DEBUG，再搜索「出站文本过滤」。日志会显示实际 UMO、规则顺序、类型、名称、命中次数、黑白名单跳过原因和是否停止后续规则。日志不包含消息原文和命中的词条或链接。无效规则仍以 WARN 记录。
